# mass-backend-senati

Repositorio de trabajo del curso **Backend Developer Web** — SENATI CFP Arequipa 2026.  
Docente: Ing. Néstor Huanqui Vela · NRC 40316

Contiene los avances de clase y tareas desarrolladas sesión a sesión, construyendo el sistema **Minimarket Mass** con PHP, MySQL y PDO siguiendo el patrón MVC.

---

## Estructura del repositorio

```
mass-backend-senati/
├── AVANCE EN CLASE/       → Prácticas desarrolladas durante las sesiones
│   ├── PRACTICAS 1/       → Ejercicios introductorios de PHP
│   └── PRACTICAS 2/       → Introducción al patrón MVC con datos hardcodeados
├── minimarket-mass/       → Sistema MVC completo conectado a MySQL
│   ├── TAREA 2/           → Test del repositorio de productos
│   ├── TAREA 3/           → Módulo de ventas con POO
│   └── TAREA 4/           → 4 reportes de inventario con PDO
└── TAREA 1/               → Boleta de trabajador con HTML/CSS/JS/PHP
```
